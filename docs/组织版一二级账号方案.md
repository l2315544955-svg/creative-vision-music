# 组织版一二级账号方案

## 目标

本项目组织版只保留两级账号，控制范围清晰，便于快速上线：

1. 一级账号：音乐公司负责人
2. 二级账号：组织成员

不继续扩展更多层级，不依赖 `ruoyi` 运行时。

## 角色定义

### 一级账号：音乐公司负责人

- 创建组织和基础信息
- 邀请或停用成员
- 充值组织资源包
- 查看团队总任务、总消耗、订单记录
- 给成员分配额度

### 二级账号：组织成员

- 使用组织额度发起歌曲生成
- 查看自己任务和作品
- 不允许管理组织计费和成员

## 一期范围

- 组织资料
- 一级/二级账号关系
- 组织充值订单
- 成员额度分配
- 团队任务列表和消耗统计

## 订单与积分原则

- 前台个人版走个人资源包
- 组织版走组织资源包
- 统一由本项目后台钱包向上游供应商结算
- 不让组织用户直接接触上游 AIZNT 充值逻辑

## 技术原则

- 可参考 `ruoyi` 的组织、账号、订单、权限写法
- 只允许复制需要的实现到本项目后再重构
- 不允许把 `ruoyi` 作为运行依赖

## 下一步接口建议

1. `POST /api/orgs`
2. `POST /api/orgs/:orgId/members`
3. `POST /api/orgs/:orgId/credit-allocations`
4. `GET /api/orgs/:orgId/overview`
5. `GET /api/orgs/:orgId/orders`
